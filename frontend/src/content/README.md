# content

All content as data. Adding a scenario or translation is a content change here, not a code change.

| Path | What | Owner |
|---|---|---|
| `concepts.json` | Every concept and misconception ID | P2 merges, everyone adds |
| `assumptions.json` | Growth, volatility, inflation, fees per fictional asset | P4 |
| `stages/` | S0–S6 definitions and gate items | P2 |
| `onboarding/` | 10 character questions, pre/post item pools | P1 |
| `scenarios/lifepath/` | Story cards, capstone | P2 |
| `scenarios/bank/`, `plan/`, `save/`, `borrow/` | Everyday Money scenarios | P3 |
| `scenarios/invest/` | Investing scenarios | P4 |
| `scenarios/safe/` | Phone scripts and inbox messages | P5 |
| `facilitator/` | Discussion prompts per misconception | P5 |
| `i18n/{en,te,hi,ur}/` | String bundles | P3 |
| `schemas/` | Schemas the content validator checks | P3 |

Create a folder when you add its first file. Audio files are not stored in git; P3 decides where they live.
